# 低价竞争执法证据链

维护低价竞争案件中的价格、成本、质量和处置证据。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括价格执法人员、质量监管人员、平台企业、被调查经营者。

资料所依据的领域事实如下：

- 专项行动综合使用价格执法、质量监管和标准引领手段
- 价格畸低且安全风险较大的产品会提高抽查力度
- 平台需要核验商品信息并配合召回

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
