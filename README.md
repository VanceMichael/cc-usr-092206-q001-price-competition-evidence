# 低价竞争执法证据链办案服务

面向市场监管部门的低价竞争案件办案服务：从线索登记到立案调查、限期申辩、
处罚决定、整改核验与复核结案的全流程，证据链只追加、处罚依据可按版本重现。

## 核心不变量

- **立案锁范围**：案件从线索进入调查时锁定商品规格、活动范围、调查时段与
  当期成本标准，锁定内容写入证据链（`调查范围锁定`）。
- **证据只追加**：平台补报、跨地区移送、口径修订、规则下线只能追加到原始
  记录之后；每条记录携带前一条的 SHA-256 哈希，任何事后改动都会被
  `verify` 检出。口径修订通过 `revises` 指向原记录，判定采用最新口径，
  原始记录仍留在链上。
- **决定钉版本**：处罚决定记录所依据的证据版本（序号与哈希），复核人员用
  `reproduce` 重现该版本的记录、判定结论与哈希链校验；决定之后追加的证据
  不影响历史版本。
- **申辩有期限**：处罚告知开启申辩期限（默认 5 天），逾期申辩与期限未满的
  决定均被拒绝；证据不足（缺成本标准或无交易证据）不能作出处罚决定。
- **秘密按授权开放**：标记 `secret` 的记录对未授权用户遮蔽，按案件授权
  （限时限人）开放，每次查阅在链上留痕（`秘密查阅留痕`）。
- **核验用同一批对象**：整改核验沿用立案锁定的商品规格与活动范围，时段取
  与锁定时段等长、截至核验日的区间；低于成本情形消失且质量联动任务办结
  方可结案。

## 判定口径（正常清仓 / 恶意倾销）

`src/assessment.py` 在锁定范围内比对交易价格与当期成本：

- 缺少成本标准或范围内无交易证据 → **证据不足**；
- 低于成本的销售均有清仓事由证明（鲜活、季节性、积压、偿债转产歇业等，
  按商品与日期覆盖）→ **正常清仓**；
- 存在无正当理由覆盖的低于成本交易 → **恶意倾销**。

价格畸低（低于成本占比 ≥ 30%）且属安全风险较大产品，或范围内抽检不合格时，
标记质量联动风险，自动发起**抽查**任务；抽检不合格另发起**召回协作**任务。

## 模块结构

| 模块 | 职责 |
| --- | --- |
| `src/models.py` | 案件状态、记录类型、调查范围、授权、联动任务 |
| `src/ledger.py` | 只追加证据链：追加、按版本前缀重现、哈希链校验 |
| `src/assessment.py` | 口径修订生效视图、倾销判定、取证缺口、质量风险 |
| `src/service.py` | 办案全流程：线索→立案→取证→告知→申辩→决定→整改→核验 |
| `src/store.py` | 内存存储与 JSON 快照持久化 |
| `src/api.py` | 标准库 HTTP 接口 |
| `scripts/demo.py` | 端到端演示一个案件的完整流程 |

## HTTP 接口

启动：`python -m src.api --port 8080 [--data store.json]`
（`--data` 指定快照文件后每次写操作自动落盘、启动时恢复）。
调用方通过 `X-User` 请求头表明身份（中文姓名用百分号编码的 UTF-8）。

| 方法与路径 | 说明 |
| --- | --- |
| `POST /cases` | 登记线索 |
| `POST /cases/{id}/open` | 立案调查并锁定范围 |
| `POST /cases/{id}/dismiss` | 不予立案 |
| `POST /cases/{id}/records` | 追加证据记录（`kind`/`payload`/`secret`） |
| `GET /cases/{id}/records?version=` | 读取记录，可按版本重现；秘密记录按授权遮蔽 |
| `GET /cases/{id}/scope` | 调查范围与取证缺口说明 |
| `GET /cases/{id}/assessment?version=` | 倾销判定（默认最新，可指定版本） |
| `POST /cases/{id}/notice` | 处罚告知，开启申辩期限 |
| `POST /cases/{id}/appeals` | 企业限期申辩 |
| `POST /cases/{id}/decision` | 处罚决定，钉住证据版本 |
| `GET /cases/{id}/reproduce?version=` | 复核人员重现处罚所依据的版本 |
| `POST /cases/{id}/grants` | 商业秘密按案件授权 |
| `POST /cases/{id}/rectifications` | 提交整改报告 |
| `POST /cases/{id}/verify` | 整改核验（同一批商品、等长时段） |
| `GET /cases/{id}/tasks` | 质量联动任务列表 |
| `POST /cases/{id}/tasks/{task}/complete` | 联动任务办结 |

金额一律以**分**为单位的整数；日期为 ISO 格式（`YYYY-MM-DD`）。

```bash
python -m unittest discover -s tests   # 运行全部测试

```

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存
不含真实个人信息的示例，由 `src/domain.py` 校验读取。仓库不保存账号、密钥、
连接串或真实身份信息；示例中的案件、人员与企业均为虚构。
